## Getting Started

### First Launch

1. **Sign Up / Sign In**
   - Open the app
   - Choose "Sign Up" to create a new account or "Sign In" if you have one
   - Options: Email/Password or Google Sign-In
   - Demo credentials available: demo@listo.app / Demo123!

2. **Permissions**
   - Grant microphone permission for voice commands

3. **Home Screen**
   - Three main tabs: Tasks, Calendar, Settings
   - Floating microphone button for voice commands

## Voice Commands

### How to Use Voice Commands

1. Tap the microphone button (bottom-right)
2. Wait for "Listening..." indicator
3. Speak your command clearly
4. Wait for voice confirmation

### Supported Commands

#### Creating Tasks

| Command | Example | Result |
|---------|---------|--------|
| Remind me to [action] | "Remind me to call John" | Creates task "call John" |
| Remind me to [action] at [time] | "Remind me to call John at 3 pm" | Task with reminder at 3 PM today |
| Add task [description] | "Add task buy groceries" | Creates task "buy groceries" |
| Create task [description] | "Create task finish report" | Creates task "finish report" |

#### Creating Events

| Command | Example | Result |
|---------|---------|--------|
| Schedule [event] | "Schedule team meeting" | Creates event "team meeting" |
| Schedule [event] at [time] | "Schedule meeting at 2 pm" | Event at 2 PM today |
| Meeting with [person] | "Meeting with Sarah tomorrow" | Event "meeting with Sarah" tomorrow |
| Appointment [description] | "Appointment dentist next Monday" | Appointment next Monday |

### Time Recognition

Listo understands various time formats:
- **Specific times**: "3 pm", "15:30", "3:30 pm"
- **Relative times**: "today", "tomorrow", "next Monday"
- **Days of week**: "Monday", "Tuesday", etc.
- **Dates**: "January 15", "March 3rd"

### Voice Accuracy Tips

For best results (~90% accuracy):
1. Speak clearly and naturally
2. Minimize background noise
3. Hold phone 6-12 inches from mouth
4. Pause briefly after tapping mic button
5. Use supported command patterns

## Troubleshooting

### Voice Commands Not Working

**Problem**: Microphone button doesn't respond
- **Solution**: Grant microphone permission in device settings
- **Check**: Ensure microphone isn't being used by another app

**Problem**: Voice not recognized
- **Solution**: Speak more clearly, reduce background noise
- **Check**: Verify internet connection (required for speech recognition)

**Problem**: Wrong command interpreted
- **Solution**: Use exact command patterns from this guide
- **Check**: Speak slowly and pause between words

### Sync Issues

**Problem**: Changes not appearing on other devices
- **Solution**: Check internet connection on both devices
- **Check**: Ensure signed in with same account
- **Wait**: Sync can take up to 30 seconds

**Problem**: Old data appearing
- **Solution**: Pull to refresh on mobile
- **Check**: Clear app cache (Settings > Storage)

### Notification Problems

**Problem**: Not receiving reminders
- **Solution**: Enable notifications in device settings
- **Check**: Verify notification time is in future
- **Check**: Battery optimization not limiting app

**Problem**: Duplicate notifications
- **Solution**: Clear app data and re-login
- **Check**: Only one device signed in (if testing)

### Login Issues

**Problem**: Can't sign in with Google
- **Solution**: Check Google Play Services (Android)
- **Solution**: Sign out of Google and sign in again
- **Check**: Internet connection stable

**Problem**: Forgot password
- **Solution**: Use "Forgot Password" link on login screen
- **Check**: Email for reset link (check spam folder)

### Performance Issues

**Problem**: App is slow
- **Solution**: Clear app cache
- **Solution**: Update to latest version
- **Check**: Available device storage (need 500MB+)

**Problem**: Battery drain
- **Solution**: Disable background sync (Settings)
- **Solution**: Reduce notification frequency
- **Check**: Close app when not in use
