## Getting Started

**Listo** is a powerful cross-platform personal assistant app that makes day-to-day organization effortless.

This project is a starting point for a Flutter application.

## 🚀 Quick Start

### Prerequisites
- Flutter SDK 3.10+
- Firebase account
- Platform-specific tools (Android Studio, Xcode, etc.)

### Installation

```bash
# Clone and install dependencies
git clone https://github.com/yourusername/listo.git
cd listo
flutter pub get

# Configure Firebase (see SETUP.md for details)
flutterfire configure

# Run the app
flutter run
```

## 🔧 Tech Stack

- **Frontend**: Flutter 3.38.3
- **State Management**: Provider
- **Backend**: Firebase (Auth, Firestore, FCM)
- **Voice**: speech_to_text, flutter_tts
- **Calendar**: table_calendar
- **Notifications**: flutter_local_notifications
