## Getting Started

**Listo** is a powerful cross-platform personal assistant app that makes day-to-day organization effortless. Add tasks, set reminders, and interact using both voice and text - all synced seamlessly across devices.

This project is a starting point for a Flutter application.

## 🚀 Quick Start

### Prerequisites
- Flutter SDK 3.10+
- Firebase account
- Platform-specific tools (Android Studio, Xcode, etc.)

### Installation

```bash
# Clone and install dependencies
git clone https://github.com/yourusername/listo.git
cd listo
flutter pub get

# Configure Firebase (see SETUP.md for details)
flutterfire configure

# Run the app
flutter run
```
